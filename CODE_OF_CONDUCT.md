# Swish community conduct

Be respectful, constructive and specific. Help people learn; critique code and
ideas without attacking people. Harassment, discrimination, threats, personal
data disclosure and repeated disruptive behavior are not welcome.

These expectations apply to this repository's issues, pull requests and project
discussion spaces. ArsDevs may moderate posts or participation to protect the
community. Report concerns through the maintainer's GitHub profile; arrange a
private channel for sensitive reports. Do not expose anyone's personal data in
a public report.
